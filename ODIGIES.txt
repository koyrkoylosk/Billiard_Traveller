BILLIARD TRAVELLER ONLINE — ΟΔΗΓΙΕΣ ΕΓΚΑΤΑΣΤΑΣΗΣ (μία φορά)
================================================================

Αρχεία του πακέτου
  index.html          -> κεντρική σελίδα με όλα τα τουρνουά
  app.html            -> η εφαρμογή (admin) + σελίδα παικτών (app.html?t=κωδικός)
  firestore-rules.txt -> κανόνες ασφαλείας της βάσης

A. Κανόνες ασφαλείας (Firebase)
  1. console.firebase.google.com -> project billiard-traveller
  2. Firestore Database -> καρτέλα «Rules»
  3. Σβήσε ό,τι υπάρχει, επικόλλησε ΟΛΟ το firestore-rules.txt -> «Publish»

B. Ανέβασμα σελίδων (GitHub Pages, δωρεάν)
  1. github.com -> Sign up (και με το Gmail). Διάλεξε όνομα χρήστη, π.χ. billiardtraveller
  2. Πάνω δεξιά «+» -> «New repository» -> όνομα: billiardtraveller -> Public -> «Create repository»
  3. Πάτα «uploading an existing file» -> σύρε μέσα index.html και app.html -> «Commit changes»
  4. Settings -> Pages -> Source: «Deploy from a branch» -> Branch: main, φάκελος /(root) -> Save
  5. Σε 1–2 λεπτά η σελίδα είναι έτοιμη:  https://<όνομα-χρήστη>.github.io/billiardtraveller/

C. Άδεια σύνδεσης Google για τη σελίδα σου (Firebase)
  1. Authentication -> Settings -> «Authorized domains» -> «Add domain»
  2. Γράψε:  <όνομα-χρήστη>.github.io   -> Add

D. Πρώτο online τουρνουά
  1. Άνοιξε https://<όνομα-χρήστη>.github.io/billiardtraveller/app.html
  2. «Admin» -> σύνδεση με το Gmail σου
  3. Συμμετοχές, κλήρωση κ.λπ. όπως πάντα (ή «Φόρτωση Backup» από το παλιό αρχείο)
  4. «Μενού» -> «☁ Online δημοσίευση»: όνομα τουρνουά + κωδικός (π.χ. 2026-10-02-athina) -> «Δημοσίευση online»
  5. «🔳 QR & σύνδεσμοι» -> Εκτύπωση. Από εκεί και πέρα κάθε σκορ ανεβαίνει αυτόματα.

E. Facebook (μία φορά)
  - Καρφιτσωμένη ανάρτηση με τον σύνδεσμο της κεντρικής σελίδας:
    https://<όνομα-χρήστη>.github.io/billiardtraveller/
  - Κουμπί σελίδας «Επισκεφτείτε τον ιστότοπο» -> ο ίδιος σύνδεσμος

Σημειώσεις
  - Οι εικόνες (αφίσα/χορηγοί) δεν ανεβαίνουν online — μένουν στον υπολογιστή σου.
  - Στη σελίδα στο internet ο admin μπαίνει ΜΟΝΟ με Google. Ο παλιός κωδικός ισχύει μόνο για το αρχείο στον υπολογιστή.
  - Η εφαρμογή σου:  https://koyrkoylosk.github.io/Billiard_Traveller/

F. Διοργανωτές (αγοραστές) που δημοσιεύουν στη σελίδα σου — από v34
  Προσθήκη διοργανωτή:
  1. Firebase -> Firestore Database -> Data -> «+ Start collection» (την 1η φορά) με Collection ID:  publishers
     (τις επόμενες φορές: μέσα στο publishers -> «+ Add document»)
  2. Document ID: το Gmail του διοργανωτή, με ΜΙΚΡΑ γράμματα (π.χ. lesxi.patras@gmail.com)
  3. Πεδία (Field / Type / Value):
       name      string   Λέσχη Πάτρας                        (φαίνεται ως «Διοργάνωση»)
       facebook  string   https://www.facebook.com/...        (προαιρετικό)
       active    boolean  true
  4. Save. Ο διοργανωτής ανοίγει τη σελίδα -> Admin -> σύνδεση με το Gmail του -> δημοσιεύει.
  Παύση άδειας:  άλλαξε το active σε false (ή σβήσε το έγγραφο). Τα τουρνουά του μένουν ορατά.
  Ο καθένας αλλάζει ΜΟΝΟ τα δικά του τουρνουά· εσύ αλλάζεις/σβήνεις τα πάντα.

G. Τραπέζια με Billiard Traveller SCOREBOARD — από v35 (στεκιές από v36)
  Μία φορά (Firebase, έργο billiard-traveller):
  1. Firestore Database -> «Rules» -> σβήσε τα παλιά, επικόλλησε ΟΛΟ το νέο firestore-rules.txt (v35) -> «Publish»
  2. Ανέβασε το νέο app.html στο GitHub (Add file -> Upload files -> Commit)

  Σε κάθε τουρνουά:
  1. Άνοιξε το τουρνουά online (app.html?t=κωδικός) και μπες Admin με Google.
  2. Στην ενότητα «🎱 Τραπέζια» βλέπεις «Τουρνουά» και «Κλειδί». Βάλε πόντους και στεκιές ανά φάση (πρόκριση / Knock Out / τελικός)
     — στεκιές 0 = χωρίς όριο — και αν ισχύει η «Τελευταία στεκιά ισοφάρισης».
  3. Σε κάθε τραπέζι: Scoreboard -> ADMIN -> καρτέλα 📱 -> «Online τουρνουά» -> γράψε κωδικό τουρνουά + κλειδί -> «ΣΥΝΔΕΣΗ».
     (Κάθε τραπέζι πρέπει να έχει αριθμό τραπεζιού στην καρτέλα 🔑.)
  4. Ο υπολογιστής του διοργανωτή μένει ΑΝΟΙΧΤΟΣ στη σελίδα του τουρνουά όσο κρατά το τουρνουά:
     αυτός στέλνει τους αγώνες στα ελεύθερα τραπέζια και κλείνει τους αγώνες που τελειώνουν.
  5. Στο τραπέζι εμφανίζεται «Επόμενος αγώνας» -> οι παίκτες πατούν «ΕΝΑΡΞΗ ΑΓΩΝΑ».
     Το σκορ φαίνεται ζωντανά στη σελίδα του τουρνουά· στο τέλος ο αγώνας κλείνει μόνος του
     και το τραπέζι παίρνει αμέσως τον επόμενο αγώνα.
  Χρήσιμα:
  - «✖ Ακύρωση» σε τραπέζι: παίρνει πίσω τον αγώνα. «➡ Αγώνας…»: στέλνει συγκεκριμένο αγώνα σε τραπέζι.
  - Ξετσεκάρισμα «Αυτόματη ανάθεση αγώνων»: οι αγώνες στέλνονται μόνο με το χέρι.
  - Αν οι παίκτες πατήσουν ΤΕΛΟΣ χωρίς νικητή, ο αγώνας γυρίζει πίσω και ξαναστέλνεται.
  - «🔑 Νέο κλειδί»: τα τραπέζια πρέπει να γράψουν ξανά το νέο κλειδί.
  - Διορθώσεις σκορ/F.F. γίνονται όπως πάντα από τον διοργανωτή· ο αγώνας που έκλεισε δεν αλλάζει από το τραπέζι.

H. Παράταση σε ισοπαλία — από v37
  - Σε ισοπαλία (π.χ. 30-30) ο αγώνας ΔΕΝ κλείνει. Πατήστε το κουμπί ⏱ στον αγώνα (μόνο ο admin το βλέπει).
  - Γράψτε τους πόντους της παράτασης με παύλα, π.χ. 3-2. Προστίθενται στο σκορ και +1 στεκιά και στους δύο (π.χ. 33-32 σε 51).
  - Νέα ισοπαλία; Ξανά ⏱ (π.χ. 35-36 σε 55 στεκιές). Μόλις βγει νικητής, «OK» κλείνει τον αγώνα και περνούν νικητής/ηττημένος.

I. ΑΠΛΗ ΔΙΟΡΓΑΝΩΣΗ (από v38) — χωρίς κωδικούς και κλειδιά
  Εσύ, μία φορά ανά πελάτη: BT Setup → πελάτης → «🏆 Gmail για διοργάνωση τουρνουά» → Αποθήκευση.
    (Την 1η φορά ανοίγει παράθυρο Google: διάλεξε το kostas.koyrkoyloss@gmail.com.)
    Ο πελάτης γίνεται αυτόματα διοργανωτής, δεμένος με το κλαμπ του.
  Ο πελάτης: εφαρμογή τουρνουά → Admin → Google με το Gmail του → συμμετοχές, κλήρωση, «Δημοσίευση online».
    Τα Scoreboard του κλαμπ του συνδέονται ΜΟΝΑ ΤΟΥΣ (λίγα δευτερόλεπτα) και αποσυνδέονται όταν τελειώσει το τουρνουά.
  Εσύ ως Billiard Traveller: στην ενότητα «🎱 Τραπέζια» γράφεις το «Κλαμπ τραπεζιών» (ακριβώς όπως στην άδεια).

J. ΕΛΕΥΘΕΡΟ ΠΑΙΧΝΙΔΙ ΤΗΝ ΗΜΕΡΑ ΤΟΥ ΤΟΥΡΝΟΥΑ (από v38 / Scoreboard v31.24)
  - «Τήρηση ωραρίου»: ένας αγώνας πηγαίνει σε τραπέζι μόνο από Χ λεπτά (προεπιλογή 30) πριν την ώρα του.
    Πριν/μετά το ωράριο τα τραπέζια είναι ελεύθερα για πελάτες. (⏩ Νωρίτερα = στέλνεται όποτε υπάρχει τραπέζι.)
  - Στο τραπέζι, στην οθόνη «Επόμενος αγώνας»: «🎱 ΕΛΕΥΘΕΡΟ ΠΑΙΧΝΙΔΙ» → το τραπέζι βγαίνει από το τουρνουά,
    ο αγώνας επιστρέφει και πάει σε άλλο τραπέζι. Κάτω αριστερά «🏆 ΤΟΥΡΝΟΥΑ: ΕΚΤΟΣ · ΕΠΙΣΤΡΟΦΗ» για να ξαναμπεί.
  - Αν παίζεται ήδη ελεύθερο παιχνίδι, ο αγώνας τουρνουά περιμένει να τελειώσει (μικρή ειδοποίηση πάνω).

K. ΕΝΑΡΞΗ ΤΟΥΡΝΟΥΑ & ΖΕΣΤΑΜΑ (από v39 / Scoreboard v31.25)
  - Στο Scoreboard το «🏆 ΤΟΥΡΝΟΥΑ» ανοίγει αυτή την εφαρμογή (στο PC: στον Chrome/Edge — εκεί δουλεύει η σύνδεση Google).
  - Συμμετοχές → κλήρωση → «🎱 Τραπέζια» → «▶ ΕΝΑΡΞΗ ΤΟΥΡΝΟΥΑ». Οι αγώνες πάνε με τη σειρά 1, 2, 3… στα ελεύθερα τραπέζια.
    «⏸ ΠΑΥΣΗ ΑΠΟΣΤΟΛΗΣ ΑΓΩΝΩΝ» σταματά τις νέες αναθέσεις (όσοι παίζονται συνεχίζουν).
  - Στο τραπέζι η οθόνη «Επόμενος αγώνας» αναβοσβήνει (με ήχο) μέχρι να πατηθεί «ΕΝΑΡΞΗ».
  - Ζέσταμα (ρύθμιση «Ζέσταμα … λεπτά», προεπιλογή 5, 0 = χωρίς): μεγάλο ασπρόμαυρο ρολόι για τον 1ο παίκτη,
    μετά ο 2ος πατά «ΕΝΑΡΞΗ ΖΕΣΤΑΜΑΤΟΣ», στο τέλος «ΕΝΑΡΞΗ ΑΓΩΝΑ». «ΠΑΡΑΛΕΙΨΗ» για όποιον δεν θέλει ζέσταμα.

L. ΠΑΡΑΤΑΣΗ, ΣΕΙΡΑ ΠΑΙΚΤΩΝ, ΔΙΟΡΘΩΣΗ (από v42 / Scoreboard v31.27)
  - Μετά το ζέσταμα: «ΣΕΙΡΑ ΠΑΙΚΤΩΝ» — ⚪ λευκή = 1ος (ξεκινά), 🟡 κίτρινη = 2ος. «⇄ ΑΛΛΑΓΗ ΘΕΣΕΩΝ» μετά το μέτρημα σειράς.
  - Ισοπαλία μετά την τελευταία στεκιά ισοφάρισης → ΠΑΡΑΤΑΣΗ στο τραπέζι (μία στεκιά ο καθένας από την αρχική θέση).
    Οι πόντοι της παράτασης ΔΕΝ μετράνε στο σκορ/στεκιές/Μ.Ο. — στο τουρνουά φαίνονται «Παράταση 5–3».
  - Διόρθωση: στο τραπέζι «✏ ΔΙΟΡΘΩΣΗ» (PIN admin)· στο τουρνουά τα πεδία πόντων/στεκιών και το ⏱ (πόντοι παράτασης).

M. ΔΙΑΓΡΑΦΗ ΤΟΥΡΝΟΥΑ (από v43)
  - Admin → Μενού → «☁ Online δημοσίευση» → «🗑 Διαγραφή τουρνουά» → γράφετε τον κωδικό του τουρνουά για επιβεβαίωση.
  - Τα τραπέζια αποσυνδέονται αμέσως (ελεύθερο παιχνίδι), σβήνονται αγώνες, αναθέσεις, σκορ και η σελίδα των παικτών.
  - Τη διαγραφή την κάνει μόνο ο διοργανωτής του τουρνουά ή ο ιδιοκτήτης της πλατφόρμας. ΔΕΝ αναιρείται.

N. ΕΓΚΑΤΑΣΤΑΣΗ ΣΑΝ ΕΦΑΡΜΟΓΗ (από v43)
  - Μία φορά στο GitHub ανεβαίνουν ΚΑΙ τα νέα αρχεία: manifest.webmanifest, sw.js, tour-icon-192.png, tour-icon-512.png,
    tour-icon-maskable.png, tour-apple-touch.png (μαζί με app.html και index.html). Μετά, σε κάθε αναβάθμιση, μόνο το app.html.
  - PC (Chrome/Edge): άνοιξε το τουρνουά → κουμπί «⬇ Εφαρμογή» πάνω δεξιά (ή εικονίδιο εγκατάστασης στη γραμμή διευθύνσεων)
    → Εγκατάσταση. Βγαίνει εικονίδιο «BT Τουρνουά» στην επιφάνεια εργασίας / έναρξη.
  - Android tablet/κινητό (Chrome): «⬇ Εφαρμογή» → Εγκατάσταση (ή ⋮ → «Εγκατάσταση εφαρμογής»).
  - iPhone/iPad (Safari): Κοινοποίηση □↑ → «Προσθήκη στην οθόνη Αφετηρίας».
  - Η εφαρμογή ανοίγει σε δικό της παράθυρο στο τελευταίο τουρνουά που άνοιξες (αλλιώς στη λίστα τουρνουά).

M2. ΔΙΑΓΡΑΦΗ ΜΕ ΑΠΟΘΗΚΕΥΣΗ (από v44 — αντικαθιστά το M)
  - «🗑 Διαγραφή τουρνουά»: το τουρνουά κρύβεται από τη λίστα, τα τραπέζια αποσυνδέονται, αλλά ΤΑ ΔΕΔΟΜΕΝΑ ΜΕΝΟΥΝ:
    στη βάση + αρχείο backup στις Λήψεις (billiard_traveller_<κωδικός>_diagrafi_….json) + τοπικά.
  - Συνέχεια: λίστα τουρνουά (index) → κάτω «♻ Διαγραμμένα» → το τουρνουά → Admin → «↩ ΕΠΑΝΑΦΟΡΑ».
  - «✖ Οριστική διαγραφή» (μόνο από το διαγραμμένο τουρνουά, γράφοντας ΟΡΙΣΤΙΚΑ): σβήνει από τη βάση· μένει μόνο το αρχείο backup
    (Μενού → «⬆ Φόρτωση Backup» για να ξαναφορτωθεί).

M3. ΔΙΑΓΡΑΦΗ / ΕΠΑΝΑΦΟΡΑ ΑΠΟ ΤΗ ΛΙΣΤΑ ΤΟΥΡΝΟΥΑ (από v45)
  - Λίστα τουρνουά → «👤 Σύνδεση» (Google). Ο ιδιοκτήτης βλέπει 🗑 σε ΟΛΑ τα τουρνουά, ο διοργανωτής στα δικά του.
  - 🗑 → OK: κατεβαίνει αρχείο backup, τα τραπέζια αποσυνδέονται, το τουρνουά πάει στα «♻ Διαγραμμένα». Χωρίς κωδικό.
  - «♻ Διαγραμμένα» → ↩ στο τουρνουά → επανέρχεται (και ανοίγει για να ξανασυνδεθούν τα τραπέζια).
  - Και μέσα στο τουρνουά: Admin → Μενού → «☁ Online δημοσίευση» → «🗑 Διαγραφή τουρνουά» → OK.

O. ADMIN ΚΛΑΜΠ ΜΕ PIN — ΕΝΑΣ ΥΠΟΛΟΓΙΣΤΗΣ ΚΑΘΕ ΦΟΡΑ (από v48)
  Μία φορά (Firebase, έργο billiard-traveller):
   1. Authentication → Sign-in method → «Anonymous» → Enable → Save.
   2. Firestore Database → Rules → επικόλληση ΟΛΟΥ του firestore-rules.txt (v48) → Publish.
  Για κάθε πελάτη (BT Setup → πελάτης):
   - «🔑 PIN admin τουρνουά»: γράψτε ή πατήστε 🎲 → ΑΠΟΘΗΚΕΥΣΗ. Δώστε το PIN στον καταστηματάρχη.
     (Αλλαγή PIN = ο συνδεδεμένος admin βγαίνει αμέσως.)
  Ο καταστηματάρχης (σε όποιον υπολογιστή ή τραπέζι θέλει):
   - Εφαρμογή τουρνουά → «Admin» → κλαμπ + PIN → ΣΥΝΔΕΣΗ. Το μηχάνημα το θυμάται.
   - Αν μπει από άλλον υπολογιστή, ο προηγούμενος βγαίνει αυτόματα (μένει σε προβολή).
  Εσύ (Gmail ιδιοκτήτη): «Admin» → «Σύνδεση με Google» → βλέπεις/αλλάζεις τα πάντα.
   - Νέο τουρνουά για πελάτη: Μενού → «☁ Online δημοσίευση» → «Κλαμπ» από τη λίστα → Δημοσίευση.
     Ο διοργανωτής γράφεται το κλαμπ και ο admin του κλαμπ το συνεχίζει με το PIN του.
  Τραπέζια: σε κάθε κάρτα τραπεζιού «✅ Παίρνει αγώνες / 🚫 Όχι αγώνες» (ένα κλικ).

P. 📲 ΕΙΔΟΠΟΙΗΣΕΙΣ ΠΑΙΚΤΗ (από v51)
  - Τυπώστε το QR του τουρνουά (Μενού → «🔳 QR & σύνδεσμοι») και βάλτε το στο μαγαζί.
  - Ο παίκτης σκανάρει → «📲 ΕΙΔΟΠΟΙΗΣΕΙΣ ΠΑΙΚΤΗ» → διαλέγει το όνομά του → «🔔 Ειδοποίησέ με» (επιτρέπει τις ειδοποιήσεις).
  - ⏳ «Ετοιμάσου»: όταν ο αγώνας του είναι επόμενος και ένα τραπέζι πλησιάζει στο τέλος
    (πόντοι ≥ απόσταση − 3, π.χ. 27/30, ή στεκιές ≥ όριο − 4, π.χ. 46/50) ή υπάρχει ελεύθερο τραπέζι.
  - 🎱 «Παίζεις τώρα»: μόλις ο αγώνας του πάει σε τραπέζι — με τραπέζι, αντίπαλο και φάση.
  - Η σελίδα πρέπει να μείνει ανοιχτή στο κινητό (ή στο παρασκήνιο / εγκατεστημένη ως εφαρμογή).
